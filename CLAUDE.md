# Portfolio website

This folder is my personal portfolio website.

## Rules

- **Plain HTML, CSS and JavaScript only.** No frameworks or libraries (no React, Vue, Tailwind, Bootstrap, jQuery, etc.) and no build tools. Every page should open directly in a browser.
- **Mobile-first.** The site must work well on mobile phones:
  - Include `<meta name="viewport" content="width=device-width, initial-scale=1.0">` on every page.
  - Use flexible layouts (flexbox/grid, percentages, `rem`, `clamp()`) instead of fixed pixel widths.
  - No horizontal scrolling on small screens; buttons and links should be easy to tap.
- **Keep the code simple and well commented.** I'm a beginner:
  - Prefer the simplest approach that works, even if it's a bit longer.
  - Add short comments explaining what each section of HTML, CSS and JavaScript does and why.
  - Use clear, descriptive names for classes, IDs, variables and functions.
  - When you change something, briefly explain what you did in plain language.
