📋 ALL COURSE PROMPTS · PART 1 of 2: Modules 1–6

━━ MODULE 1: WHAT IS AN LLM? (2:00) ━━

1. What is a token?
Explain in simple words what a "token" is for an AI model. Then split this sentence into approximate tokens and show them in a table: "Claude helps small businesses save hours every week."

2. Test for hallucination
Give me three research papers about marketing for small bicycle shops, with authors, year and journal.

3. Fact-check with web search
Please search the web and check whether each of these papers really exists. Be honest about anything you can't verify.

4. What is an API?
I'm a complete beginner. Explain what an API is using a restaurant analogy. Then show a short, simple example of a JSON request that an app would send to an AI model's API to ask "Write a haiku about bicycles", and explain each line in one sentence.


━━ MODULE 2: WHAT IS AN AI AGENT? (8:53) ━━

1. Watch the agent loop
Find three well-reviewed bicycle repair shops in Oslo. For each one, find its Saturday opening hours and the price of a basic service. Then compare them in a table and recommend one, with links to your sources.

2. Test your n8n agent
Who founded Wikipedia, and in which year? Then calculate 17% of 2,350 euros.


━━ MODULE 3: GETTING STARTED (16:24) ━━

1. Your first message
Hi Claude! I'm completely new to AI. In three short bullet points, what can you help me with this week?


━━ MODULE 4: THE CLAUDE INTERFACE (23:35) ━━

1. Quick task (Haiku)
Summarise in one line: Northside Bike Repair fixes bikes and e-bikes, lends a free bike during repairs, and has been open since 2015.

2. Deep thinking (Opus)
I want to start a small online business teaching AI skills to beginners, with a budget of 500 euros. Think it through carefully and give me a 90-day plan in 8 bullet points, including the biggest risk.

3. Incognito chat test
Hello! Will you remember this chat?


━━ MODULE 5: PROMPT ENGINEERING (32:59) ━━

1. A weak prompt (before)
Write an about me section for my website.

2. The five-box prompt (after)
ROLE: You are an expert personal-brand copywriter.
GOAL: Write the "About me" section of my portfolio website, so that small businesses want to hire me to help them use AI.
CONTEXT: My name is Abraham. I'm a software developer based in Norway. I build AI automations and run the YouTube channel "AI, Actually", where I explain AI tools in plain English. I like making complicated tech feel simple.
FORMAT: A headline of up to 8 words, then two short paragraphs (max 90 words in total), then a one-line call to action.
RULES: First person. Warm and confident, not salesy. No clichés like "passionate" or "results-driven". No emojis.

3. Teach by example
Now write 3 one-line descriptions for projects on my portfolio. Match the style of these two examples exactly: Example 1: "Inbox Zero Bot: an n8n agent that sorts 200 emails a day, so the team only reads what matters." Example 2: "Shop Assistant: a Claude Project that answers customer questions from the shop's own price list." My projects: a YouTube channel about AI; a portfolio website built with Claude Code; an AI workflow that turns meeting notes into tasks.

4. Structure with XML tags
<instructions>Compare the two job adverts below. Give me a table of the skills they share, then the skills that appear in only one of them.</instructions>
<advert_1>Junior AI Developer. Python, REST APIs, prompt engineering, Git. Nice to have: n8n or Zapier.</advert_1>
<advert_2>Automation Specialist. n8n, APIs and webhooks, JSON, good communication. Nice to have: Claude or OpenAI experience.</advert_2>

5. Let Claude ask first
I want to plan my personal portfolio website. Before you suggest anything, ask me 5 short questions, one per line, that you need answered to plan it well.

6. Ask for alternatives
Great. Now give me two alternative versions of the homepage headline: one more professional, one more playful.


━━ MODULE 6: RESEARCH, FILES AND IMAGES (42:10) ━━

1. Web search with sources
What are the 5 most in-demand AI skills for freelancers right now? Keep it short and cite a source for each one.

2. Deep Research report
Research what makes a great developer or freelancer portfolio website in 2026: the sections that matter most, common mistakes, and three good examples. Give me a short report with sources.

3. Read a file (your CV)
Read my CV and list my 5 strongest skills and my 3 most impressive projects, as bullet points I could use on a portfolio website.

4. Read an image (screenshot)
Look at this website screenshot. Describe its layout, colours and fonts, and tell me which three ideas I could borrow for my own portfolio.
